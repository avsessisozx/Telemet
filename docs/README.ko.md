DJI Osmo Action 카메라는 DJI **GPS 블루투스 리모컨**이 연결되어 있을 때만 속도, 경로, 고도를 영상에 기록합니다. Telemet은 휴대폰을 그 리모컨으로 바꿔 줍니다. 블루투스로 카메라에 연결해 휴대폰의 GPS를 초당 10회 보내고, 카메라가 이를 영상 파일에 바로 기록합니다. **DJI Mimo** 또는 **DJI Studio**에서 영상을 열고 속도/경로/고도 대시보드를 추가하면 끝입니다. FIT 변환도, 추가 장비도 필요 없습니다. 모터사이클용으로 만들었지만 자전거, 자동차, 도보에서도 똑같이 작동합니다.

## 기능

- 📍 **DJI GPS 리모컨 에뮬레이션**: 데이터가 영상에 바로 삽입됩니다
- 🎬 **카메라 제어**: 앱이나 알림에서 녹화 시작/중지, 모드·녹화 상태·배터리 표시
- 🗂️ **주행별 저장**: "내 주행"을 날짜별로 묶어 거리, 시간, 최고/평균 속도, 상승 고도 표시
- 💾 **주행마다 FIT + GPX 백업**: 카메라가 데이터를 놓쳐도 FIT를 DJI Studio로 가져올 수 있습니다
- 🏍️ **뱅크각과 G-포스**: 자이로와 GPS로 계산, 휴대폰 거치 방식과 무관
- 🎞️ **동영상과 맞추기**: 카메라는 긴 녹화를 여러 파트로 나눕니다. 파트를 선택하거나(갤러리에서 Telemet으로 공유) 파트별 FIT + GPX 또는 하나로 합친 파일을 만듭니다
- 🟩 **계기판 동영상**: 속도, 뱅크각, G, 고도, 거리, 미니맵을 녹색 배경에 각 파트의 크기와 길이로 만들어 크로마 키로 동영상 위에 올립니다
- 🎛️ **DJI Mimo에서 뱅크각과 G** (선택): 케이던스와 파워 필드에도 기록
- 🤖 **자동 녹화** (선택): 출발하면 녹화를 시작하고 3분 정지하면 멈춥니다
- 📈 **기압 고도**: 기압계가 있는 휴대폰에서 더 안정적인 고도와 경사
- 🔋 **내비게이션 앱처럼 동작**: 화면이 꺼지거나 다른 앱이 앞에 있어도 계속 기록
- ⚡ **빠른 첫 위치 확인**: 앱을 열면 GPS 예열, 신호 전과 터널 구간의 공백을 채움
- 🌍 **12개 언어** · 🔓 **무료 오픈 소스**: 광고·계정·인터넷 불필요

## 다운로드 및 설치

1. 휴대폰에서 **[최신 버전](https://github.com/avsessisozx/Telemet/releases/latest)**을 엽니다.
2. **Telemet-x.y.z.apk**를 눌러 다운로드한 뒤 엽니다.
3. 출처를 알 수 없는 앱 경고가 나오면 브라우저나 파일 관리자의 설치를 허용합니다.
4. 새 버전은 기존 버전 위에 설치되며 주행 기록은 유지됩니다.

> **이 페이지에서만 다운로드하세요.** 서명 키는 공개되어 있습니다(오픈 소스). 다른 곳의 APK는 정식 앱 위에 설치되는 변조된 사본일 수 있습니다.

## 빠른 시작

1. **카메라**에서 무선 연결을 켭니다. 휴대폰의 **DJI Mimo를 닫으세요**. 카메라는 한 번에 리모컨 하나와만 통신합니다.
2. Telemet을 엽니다. **설정** 카드가 필요한 권한을 차례로 안내합니다 (위치 "항상 허용", 블루투스, 알림, 배터리, Xiaomi는 자동 시작과 배터리 절약도).
3. **시작**을 누릅니다. 처음에는 카메라 화면에서 연결을 승인합니다 (앱의 코드와 같아야 함).
4. GPS 점이 초록색이 되면 카메라나 Telemet에서 녹화를 시작합니다.
5. 끝나면 **중지**를 누릅니다. 주행이 **내 주행**에 추가되고 FIT/GPX 파일은 `다운로드/Telemet`에 저장됩니다.

## DJI Studio에서 FIT 백업 사용하기

**내 주행**에서 주행을 컴퓨터로 공유 → DJI Studio에서 영상 열기 → **대시보드** → **데이터 소스** → **FIT 파일 가져오기** → 필요하면 **시간 맞추기**.
