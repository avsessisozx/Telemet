<h1 align="center">Telemet</h1>

DJI Osmo Action カメラは、DJI の **GPS Bluetooth リモコン**が接続されているときだけ、速度・ルート・高度を動画に記録します。Telemet はスマホをそのリモコンに変えます。Bluetooth でカメラに接続し、スマホの GPS を毎秒 10 回送信、カメラがそのまま動画ファイルに書き込みます。**DJI Mimo** や **DJI Studio** で動画を開き、速度・ルート・高度のダッシュボードを追加するだけ。FIT 変換も追加機材も不要です。バイク向けに作られていますが、自転車・車・徒歩でも同じように使えます。

## 主な機能

- 📍 **DJI GPS リモコンを再現**：データは動画に埋め込まれます
- 🎬 **カメラ操作**：アプリや通知から録画開始/停止、モード・録画状態・バッテリーを表示
- 🗂️ **走行ごとに保存**：「走行記録」を日付別に表示（距離・時間・最高/平均速度・獲得標高）
- 💾 **走行ごとの FIT + GPX バックアップ**：カメラがデータを取り逃しても FIT を DJI Studio に読み込めます
- 🏍️ **バンク角と G**：ジャイロと GPS から計算、スマホの取り付け方に左右されません
- 🎞️ **動画と照合**：カメラは長い録画を分割します。分割された動画を選ぶ（またはギャラリーから Telemet に共有する）と、パートごとの FIT + GPX、または 1 つにまとめたファイルを作ります
- 🟩 **メーター動画**：速度・バンク角・G・高度・距離・ミニマップを緑背景に描き、各パートと同じサイズと長さで出力。クロマキーで動画に重ねます
- 🎛️ **DJI Mimo でバンク角と G**（任意）：ケイデンスとパワーの欄にも書き込みます
- 🤖 **自動録画**（任意）：走り出すと録画を開始し、3 分停止すると止めます
- 📈 **気圧高度**：気圧計付きのスマホでは高度と勾配が安定
- 🔋 **ナビアプリのように動作**：画面オフや他のアプリ使用中も記録を継続
- ⚡ **すばやい測位**：アプリを開くと GPS を事前起動、測位前やトンネル内の空白を補完
- 🌍 **12 言語** · 🔓 **無料・オープンソース**：広告なし、アカウント不要、ネット不要

## ダウンロードとインストール

1. スマホで **[最新リリース](https://github.com/avsessisozx/Telemet/releases/latest)** を開きます。
2. **Telemet-x.y.z.apk** をタップしてダウンロードし、開きます。
3. 不明なアプリの警告が出たら、ブラウザまたはファイル管理アプリからのインストールを許可します。
4. 新しいバージョンは上書きインストールでき、走行記録は残ります。

> **ダウンロードはこのページからのみ行ってください。** 署名キーは公開されています(オープンソース)。他の場所の APK は、本物のアプリに上書きインストールされる改ざん版かもしれません。

## クイックスタート

1. **カメラ**でワイヤレス接続を有効にします。スマホの **DJI Mimo を閉じてください**（カメラは同時に 1 台のリモコンとしか通信しません）。
2. Telemet を開きます。**セットアップ**カードが必要な権限を順に案内します（位置情報「常に許可」、Bluetooth、通知、バッテリー。Xiaomi は自動起動と省電力も）。
3. **開始**をタップ。初回はカメラ画面で接続を承認します（アプリのコードと一致すること）。
4. GPS の点が緑になったら、カメラまたは Telemet から録画を開始します。
5. 終わったら**停止**をタップ。走行は**走行記録**に追加され、FIT/GPX ファイルは `ダウンロード/Telemet` に保存されます。

## DJI Studio で FIT バックアップを使う

**走行記録**から走行をパソコンに共有 → DJI Studio で動画を開く → **ダッシュボード** → **データソース** → **FIT ファイルをインポート** → 必要なら**時間の位置合わせ**。
